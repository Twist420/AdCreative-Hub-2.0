# 需求中心协同看板：跨周期方向收口与投放打包需求

## 背景

当前需求中心已经有协同看板、需求大表、制作排期和成品上传等能力。常规流程是：

1. 创意负责人提出方向。
2. 在协同看板中新建方向和需求。
3. 制作负责人进行排期。
4. 制作进度回传到需求中心。
5. 制作完成后，投放把同一批素材打包到一个 set 中投放。
6. 投放数据再回流到需求、版本和方向。

现实问题是，一个周期下的方向通常不会整齐完成：

- 有些方向完全没开始，周期结束时可能关闭，也可能挪到下个周期。
- 有些方向只做了一半，需要在新周期里重新承接未完成素材。
- 投放侧需要知道哪些素材属于同一个方向、哪些素材已经能打包、是否还有同方向素材快完成。
- 开会同步时，领导关心的不是单条需求，而是方向维度：每个方向有哪些素材、完成到哪一步、历史未完成方向是否还要继续、未完成方向和未来待排期素材的优先级关系。

因此，本需求不新增独立页面，而是在现有需求中心的“协同看板”里迭代，强化方向跨周期管理、未完成方向收口、投放打包建议和会议同步能力。

## 目标

### 业务目标

- 让协同看板从“当前周期方向卡片”升级为“方向收口和跨周期关联入口”。
- 周期结束时，能快速看清哪些方向完成、哪些未完成、哪些需要关闭或结转。
- 开会时能把历史未完成方向、当前制作方向、未来未排期素材放在一起比较优先级。
- 投放侧能基于方向和素材状态看到可打包 set 建议，减少人工找素材。

### 产品目标

- 保持现有协同看板作为主入口，不拆出新模块。
- 保留当前周期卡片视图，同时增加面向收口和同步的快速筛选。
- 结转、关闭、优先级调整必须由人确认；系统只做识别、提示和建议。
- 投放打包先做“建议和确认”，后续再考虑自动上传和自动建 set。

## 角色与核心问题

### 创意负责人

- 需要知道本周期每个方向的素材完成情况。
- 需要决定未完成方向是否继续、关闭、降级或提高优先级。
- 需要在开会时快速回答：之前没做完的还有哪些，为什么没做完，还值不值得继续。

### 制作负责人

- 需要看到方向下的未完成素材，以及是否要结转到下周期。
- 需要知道未完成素材和未来新素材的优先级关系。
- 需要避免旧方向不断遗留但没有明确处置。

### 投放负责人

- 需要知道哪些素材属于同一个方向。
- 需要知道哪些素材已经完成且未投放、哪些已投放。
- 需要知道同方向是否还有快完成素材，是否应该等齐再打包。

### 管理者

- 需要在会议中从方向维度看进度，而不是进入每条需求详情。
- 需要快速调整方向和素材优先级。
- 需要看到跨周期遗留风险。

## 概念定义

### 方向继承关系 Direction Rollover

方向继承关系用于轻量保留跨周期方向之间的关系，不新增独立的方向主对象。

一个方向如果没有在当前周期完成，可以在下周期创建一个继承方向。继承方向沿用首个排期方向编号或名称，并明确标注“继承自某周期方向”。

示例：

- `冰雪 sort 玩法方向`。
- 下周期仍叫 `冰雪 sort 玩法方向`，但显示 `继承自 2026-06 第 3 周`。

方向继承关系只解决追溯和筛选问题，不引入新的方向主数据层。

### 周期排期 Schedule

周期排期就是协同看板中的方向卡片。当前代码里的 `CreativeSchedule` 更接近这个概念。

跨周期时，新周期会生成一个新的方向卡片，但通过 `继承来源` 字段与上一周期方向关联。

### 素材需求 Requirement

素材需求是方向下具体要制作的一条素材。它继续保留现有需求状态、制作状态、投放状态。

### 投放集合 Delivery Set

投放集合是投放侧把一批素材打包投放的集合。它可以由系统建议生成，但必须由投放负责人确认。

一个方向下可以有多个 Delivery Set。当前规则下，同一方向里的语言和素材类型默认一致，可以放在一起；主要拆分限制是渠道，因为不同渠道对一个 set 中可上线素材数量的要求不同。

## 方向收口状态

协同看板中的方向需要新增或派生以下收口状态：

| 状态 | 含义 | 典型动作 |
| --- | --- | --- |
| 进行中 | 当前周期正在制作或等待制作 | 新建需求、排期、查看进度 |
| 部分完成 | 周期已接近结束且方向未全部完成，或有素材完成也有素材未完成 | 决定关闭、结转、继续观察；需要继续时手动选择未完成素材 |
| 完全未开始 | 方向下没有素材进入制作 | 关闭或挪入下周期 |
| 全部完成且未投放 | 方向下素材全部完成，且尚未进入投放 | 生成 set 建议 |
| 已投放 | 已创建投放 set 或已开始投放 | 查看投放回流 |
| 已关闭 | 明确不再推进 | 保留历史，不进入默认待办 |
| 暂缓 | 暂时不排期，但未来可能恢复 | 降低优先级，保留观察 |

这些状态不一定都要手填，第一版可以由系统根据素材状态派生，并允许有权限的用户手动覆盖为“已关闭 / 暂缓”。所有周期结束前后未全部完成的方向，统一进入“部分完成”决策。

### 收口状态判定补充

| 状态 | 触发条件 | 需要决策 |
| --- | --- | --- |
| 部分完成 | 周期已接近结束且方向未全部完成，或有素材完成也有素材未完成 | 手动选择未完成素材结转，或决定继续观察 / 关闭 |

## 协同看板改造范围

### 1. 顶部快速筛选增强

在现有协同看板筛选区增加一组会议常用快捷筛选：

- 当前周期方向
- 所有未完成方向
- 跨周期遗留
- 完全未开始
- 部分完成
- 全部完成且未投放
- 快完成可等待
- 高优先级未排期
- 已关闭 / 暂缓

筛选结果仍然展示方向卡片，但可以跨周期展示，不局限于当前选中周期。

### 2. 方向卡片增加收口信息

方向卡片在现有基础上增加以下信息：

- 方向收口状态。
- 关联周期：当前周期 / 来源周期 / 结转到的周期。
- 继承标记：是否继承自上一周期方向。
- 素材统计：总数、已完成、制作中、未开始、全部完成未投放、已投放。
- 历史遗留标记：是否来自上周期或更早周期。
- 建议动作：关闭、结转、等待快完成、生成 set、调整优先级。

卡片示例信息：

```text
冰雪 sort 玩法方向
高优 · 来源 2026-06 第 3 周 · 部分完成
素材：已完成 3 / 制作中 2 / 未开始 4
投放：3 条可打包，2 条预计 1 天内完成
建议：先确认是否等待快完成素材，再生成投放 set
```

### 3. 方向详情弹窗增加“收口决策区”

点击方向卡片后，在现有方向详情弹窗中增加“周期收口”区域。

区域包含：

- 该方向下所有素材列表。
- 按状态分组：已完成、制作中、未开始、已投放、暂停。
- 每条素材显示需求编号、素材类型、负责人、制作状态、预计完成时间、投放状态。
- 对未完成素材支持勾选。
- 支持以下动作：
  - 关闭方向。
  - 暂缓方向。
  - 结转选中素材到下周期。
  - 调整选中素材优先级。
  - 标记不再制作。

重要规则：

- 结转不能自动执行，必须人工勾选素材。
- 结转后，新周期中创建同方向的新排期记录，并标注继承来源。
- 原周期保留历史记录，不删除原需求。
- 被结转素材复用原需求编号，需求本身不变，只是挂靠到新的继承方向。

### 4. 未完成方向集中视图

协同看板增加“未完成方向”快捷视角，本质是筛选后的卡片集合，不新增独立路由。

默认排序建议：

1. 最高优先级且有制作风险的方向。
2. 跨周期遗留时间最长的方向。
3. 快完成但未投放的方向。
4. 完全未开始但优先级高的方向。

每张卡片必须能直接调整方向优先级，避免会议中来回进入详情。

### 5. 投放打包建议

当方向下存在已完成且未投放素材时，系统生成 Delivery Set 建议。

建议规则：

- 同一方向或同一继承方向链路。
- 素材制作状态为已完成。
- 需求状态为已通过或可投放。
- 投放状态为未投放。
- 按渠道拆分；语言和素材类型默认跟随方向，不作为第一版拆分条件。
- 没有被标记为暂停、废弃或不再制作。

系统需要提示：

- 当前可打包素材数量。
- 同方向是否还有制作中且预计短期完成的素材。
- 是否建议等待。
- 如果不等待，当前 set 覆盖哪些素材。

第一版不直接自动上传或自动建 set，只生成“建议 set”，由投放负责人确认。

后续可扩展：

- 确认后自动生成 set 名称。
- 自动创建投放任务。
- 接入投放平台上传。
- 回写 set ID、投放状态和投放数据。

## 核心流程

### 流程一：当前周期正常推进

1. 在协同看板创建方向。
2. 在方向下新建素材需求。
3. 制作排期推进任务。
4. 成品上传后需求进入已完成。
5. 协同看板方向卡片显示制作完成进度。
6. 方向全部素材完成且未投放时，卡片出现“全部完成且未投放”提示。

### 流程二：周期结束，方向完全未开始

1. 用户进入协同看板，点击“完全未开始”筛选。
2. 系统展示本周期或历史周期中没有任何素材进入制作的方向。
3. 用户选择：
   - 关闭方向。
   - 暂缓方向。
   - 挪入下周期。
4. 若挪入下周期，系统创建新周期方向卡片，并标注继承来源。

### 流程三：周期结束，方向部分完成

1. 用户进入“部分完成”或“所有未完成方向”筛选。
2. 打开方向详情弹窗。
3. 系统按素材状态展示：已完成、制作中、未开始。
4. 用户手动勾选要继续推进的素材。
5. 用户选择“结转到下周期”。
6. 系统在下周期创建同方向排期，并把选中素材的挂靠方向切换到新的继承方向。
7. 原周期卡片保留部分完成状态和历史记录。

### 流程四：投放判断是否等待快完成素材

1. 投放进入协同看板，点击“全部完成且未投放”或“快完成可等待”。
2. 系统展示可打包方向。
3. 卡片提示：已完成素材数量、制作中且预计完成时间较近的素材数量。
4. 投放选择：
   - 立即生成建议 set。
   - 等待快完成素材。
   - 排除部分素材后生成建议 set。
5. 确认后，系统记录 Delivery Set 草稿。

### 流程五：会议中调整优先级

1. 用户点击“所有未完成方向”。
2. 系统展示跨周期未完成方向和当前周期未完成方向。
3. 用户按优先级、进度、风险、预计完成时间排序。
4. 用户直接在方向卡片或批量操作区调整优先级。
5. 方向优先级只同步到当前方向和继承方向链路；单条素材优先级允许与方向优先级不一致。

## 数据字段建议

不新增独立方向主结构，只在现有方向排期和需求上补充轻量关联字段。

### CreativeSchedule

现有 `CreativeSchedule` 建议补充：

```ts
inheritedFromScheduleId?: string;
inheritedToScheduleIds?: string[];
inheritanceLabel?: string;
rolloverStatus?: 'None' | 'PartialCompleted' | 'CarriedOver' | 'Closed' | 'Deferred' | 'Observing';
closePermissionRole?: 'Owner' | 'Lead' | 'Admin';
closeReason?: string;
decisionNote?: string;
```

### Requirement

现有 `Requirement` 建议补充：

```ts
inheritedFromScheduleId?: string;
currentScheduleId?: string;
rolloverStatus?: 'None' | 'CarriedOver' | 'Dropped' | 'Closed';
deliverySetId?: string;
doNotProduceReason?: string;
```

### Delivery Set

建议新增：

```ts
interface DeliverySet {
  id: string;
  scheduleId: string;
  inheritedFromScheduleId?: string;
  scheduleIds: string[];
  requirementIds: string[];
  status: 'Draft' | 'Confirmed' | 'Uploaded' | 'Delivering' | 'Paused';
  channel: string;
  setName: string;
  createdBy: string;
  createdAt: string;
  confirmedAt?: string;
  externalSetId?: string;
}
```

## 展示与交互规则

- 协同看板默认仍展示当前周期方向。
- 用户点击“所有未完成方向”后，允许跨周期展示方向卡片。
- 已关闭方向默认不展示，只在用户选择“已关闭 / 暂缓”时出现。
- 结转动作必须二次确认，并展示会被结转的素材列表。
- 关闭方向必须填写原因或选择原因，并且只有方向负责人、组长或管理员可操作。
- 批量调整优先级时，需要提示影响范围：当前方向、继承方向链路、未完成素材；但允许单条素材优先级与方向优先级不一致。
- 投放 set 建议必须允许人工排除素材。
- 已投放素材不能被重复加入新的 Delivery Set，除非用户明确选择“复投”。

## 第一版范围

第一版建议只做前端可验证闭环：

1. 协同看板增加会议常用快捷筛选。
2. 方向卡片展示方向收口状态、遗留标记、继承标记、素材状态统计和建议动作。
3. 方向详情弹窗增加收口决策区。
4. 支持手动关闭、暂缓、结转选中素材。
5. 支持未完成方向集中查看和快速调整优先级。
6. 支持 Delivery Set 建议草稿，不接真实投放平台。

暂不做：

- 自动上传投放平台。
- 自动创建真实广告 set。
- 自动决定哪些素材结转。
- 自动调整排期。
- 与飞书会议纪要或审批流联动。

## 验收口径

- 在协同看板中，用户能一键筛出所有未完成方向。
- 在协同看板中，用户能一键筛出跨周期遗留方向。
- 在协同看板中，用户能看到一个方向下已完成、制作中、未开始、全部完成未投放素材数量。
- 对完全未开始方向，用户能选择关闭、暂缓或挪入下周期。
- 对部分完成方向，用户能手动选择未完成素材并结转到下周期。
- 结转后，新周期能看到继承方向，原周期仍保留历史记录，需求编号不变化。
- 投放能看到某方向当前可打包素材，以及是否还有 1 天内快完成素材。
- 用户能生成 Delivery Set 草稿，并看到草稿包含哪些素材。
- 会议中，用户能在未完成方向视图里快速调整方向优先级。

## 已确认规则

- 不建立独立方向主对象，使用方向之间的继承关系保留跨周期关联。
- 继承方向沿用首个排期方向编号或名称，并标注“继承自某周期方向”。
- 结转后的素材复用原需求编号，需求本身不变，只是换挂靠方向。
- “快完成”阈值默认 1 天。
- Delivery Set 按渠道拆分；同一方向内语言和素材类型默认一致，可以放在一起。
- 关闭方向需要权限控制，默认仅方向负责人、组长或管理员可关闭。
- 方向优先级和单条素材优先级允许不一致。
